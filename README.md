# ユニトラ（Unit Tracker）

![](/assets/readme1.png)

大学生向けの履修・単位管理iOSアプリです。  
時間割管理、出席記録、課題管理、成績確認を一つのアプリで完結できるよう開発しました。

## 開発背景

　このアプリを開発するした背景として、オンラインで開催された「バイブコーディングの学習を目的としたハッカソン」への参加がありました。今までは自分でのコードの記述が基本で、AIでのコード生成は補助的なものとして使用してきましたが、このハッカソンで初めてClaudeCodeを利用してバイブコーディングに挑戦しました。

　題材選定はwebやiosアプリ、拡張機能など完全に自由で、唯一言われていたのが「自分自身が使いたいもの、必要としているもの」ということでした。

　私は開発当時（2026年5月時点）現役大学生として、履修登録や出席数、単位の管理方法が難しいと感じていました。他大学ではそれらを管理するツールが大学側で用意されていたようなのですが、私の大学にはそれがなく、成績をもっと簡単に管理できるアプリがあれば使ってみたいかも、と開発を始めました。

　今までの個人開発ではJavaScriptやReactでのwebアプリやHP制作のみだったので、今までハードルが高く挑戦できずにいたiosアプリの開発に、バイブコーディングでなら今でも可能なのではと感じたのも理由の一つです。

- 出席機能とその動線のシンプルさ
- 成績を視覚的に、かつ単純にユーザーに伝えること
- UI,UXを整えて、ストレスなく利用できる設計にすること

などを開発では意識することで日常的にアプリを使用する上での手間やストレスを少なくすることを目的として開発しました。

---

## 主な機能

- 時間割の登録・表示（グリッド形式）
- 講義ごとの出席記録（出席 / 欠席 / 遅刻 / 休講）
- 課題の登録・提出状況管理
- 成績・出席状況の管理
- ログ機能（出席・課題などの活動履歴を視覚化）

## 工夫した点

### 時間割グリッドのUI,操作性

曜日 × 時限のグリッドレイアウトを `TimetableGrid` コンポーネントとして実装しました。  
講義登録後は時間割画面にて講義をタップするだけで詳細画面に遷移できるようにすることで、直感的な操作性を意識しました。

---

### 出欠ステータスの細分化

出席管理では「出席 / 欠席 / 遅刻 / 公欠」の4ステータスを用意し、  
実際の大学の出席管理ルールに近い形で記録できるように設計しました。

---

### 各機能や画面でのUIの統一

ClaudeCodeでのバイブコーディングのため、機能面での細かな指示出しをするにつれて全体のUIの統一感が崩れ、結果として動線も複雑になることでUXが乱れてしまうのが課題でした。
類似のアプリやデザインを参考に、機能を選定し、色数や表記を限定しながら、アプリとして違和感なく利用できるUIにすることができました。

## セットアップ

```bash
git clone https://github.com/soundPorco/unit-tranker.git

cd unit-tranker

npm install
```

`.env` ファイルを作成し、Supabase の接続情報を設定します。

```
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Supabase のテーブルを作成します（SQL Editor で実行）。

```bash
# supabase_setup.sql を Supabase SQL Editor で実行
```

アプリを起動します。

```bash
npx expo start
```
